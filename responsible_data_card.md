# Responsible Data Card

## Dataset Name
Synthetic Student Academic Performance Dataset

## Purpose
Demonstrate responsible planning for an educational ML project.

## Data Source
Synthetic data created for demonstration.
No real student records are included.

## Proposed Features
- Attendance percentage
- Weekly study hours
- Assignment completion rate
- Previous assessment score

## Target Variable
Illustrative academic performance category.

## Intended Use
Educational research and demonstration of ML concepts.

## Out-of-Scope Uses
- Automatic student admission or rejection
- Punitive action against students
- Solely automated decisions about student futures

## Privacy Risks
Educational information can be sensitive.
Use synthetic or properly authorized data and minimize collection.

## Bias Risks
Attendance and previous scores may reflect circumstances beyond
a student's control. The model may produce unequal errors.

## Risk Mitigation
- Evaluate errors across relevant groups where appropriate.
- Document limitations.
- Provide human review.
- Do not use predictions as the sole basis for decisions.

## Data Quality
The proposed features require validation for accuracy,
completeness, relevance, and representativeness.

## Limitations
This card describes a proposed system, not a validated model.
No claims of predictive accuracy are made.
